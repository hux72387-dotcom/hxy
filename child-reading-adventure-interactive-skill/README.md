# child-reading-adventure-interactive

🎨 Enhanced child reading adventure designer with interactive HTML output.

In addition to the original Markdown/DOCX/PDF output, this skill generates **interactive HTML handbooks** with drag-and-drop, clickable choices, mind maps, sound tracks, rule labs, role stages, and a night-sky collection — all playable in a browser with no installation.

## Features

- 📖 Full original skill: content grounding, safety, child agency, quantitative gates
- 🖱️ Interactive HTML output: self-contained, offline-first, works at `file://`
- 🎮 8 interactive mechanics: clue collector, path chooser, sound track, mind map, rule lab, role stage, stamp trail, star collection
- 🔒 No external dependencies, no CDN, no analytics, no personal data collection
- 📱 Responsive: phones (375px), tablets (768px), laptops (1024px+)
- ♿ Accessible: keyboard navigation, focus states, large touch targets

## Installation

```
/install_skill_from_url https://github.com/hux72387-dotcom/hxy/tree/main/child-reading-adventure-interactive
```

## Output Modes

| Mode | Output |
|------|--------|
| `ideas` | Bounded set of ideas |
| `plan` | Adult-facing plan (Markdown) |
| `full` | Adult plan + child handbook (Markdown) |
| `interactive` | Adult plan + interactive HTML handbook |
| `full+interactive` | Adult plan + Markdown handbook + interactive HTML |
